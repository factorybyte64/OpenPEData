## The five most important new points

1. **Data type "Configuration string"** for interface properties (pp. 28–30) = **WString, code 14, already covered** (correction 2026-10-31): TIA shows the type as "WString (Configuration string)" (user's screenshot 2026-10-23; TIA help "Configure interface property" and "Overview" name the same 11 types), created in F16 as P_String, instance value "abc" confirmed against Openness in F18b. The entry does not go beyond that: free text of arbitrary length without a fixed format, set via script (`Screen.Items(...).Properties.<Name> = "..."`) and bound to a string property via property interface dynamization (example: filter of an alarm control); not intended for text properties (use "Multilingual text" for those). The TIA readme additionally mentions its use as a substitute for multilingual texts in pop-ups (language variants separated by semicolons, evaluated in the script). Only the property interface dynamization itself remains open (LIST 8, F17).
2. **Lowest device version** = `MinimumTargetDeviceVersion` of the version (pp. 6–7). We already read the value; a sample with "Upgrade device version" shows whether only this attribute changes or a new version is created.
3. **Interface Inheritance** with nesting and pop-up (pp. 14, 50–51): interfaces are passed through automatically if the definition is the same, events are not. This is the missing part of F30 (type with interface inside a type with the same interface).
4. **Event handler via the function list** with event parameters (p. 31, from V20 Upd 3) as an alternative to the script handler from F18b; storage likely like other function lists (HmiFunctionListEmbeddedData), not confirmed.
5. **Texts and versions:** library text import with automatic version increment (p. 35) as well as AlwaysDownload/DefaultName for pop-ups (p. 52). Both change type and version in ways we have not sampled yet (multilingualism, AlwaysDownload True).

Others, runtime/editor only: header and fit-to-size on the container, IndependentWindow positioning, scroll behavior of pop-ups, interface preview.
