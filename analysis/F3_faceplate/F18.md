## Storage location

`ILFaceplateTypeData.IFaceplateInterface.InterfaceEvents` = CoreMapArray, one map per event:

```
{Name: "EvTest", _Guid: 4427a2ea-…, _TypeId: -66604,
 InterfaceEventParameters: [ {Name: "Nr",   _Guid: cbd7428d-…, _TypeId: -66605},
                             {Name: "Flag", _Guid: c610a7f4-…, _TypeId: -66605, DataType: "Bool"} ]}
```

- `InterfaceEventParameters` is itself a list of maps (type code 0xcd4001, CoreMapArray, CONTROLS.md).
- The data type of a parameter is stored **as a name** (string, "Bool"), not as a code as for tags and properties. For Int it is missing: Int is the default data type of a parameter and is not stored (the user created Nr as Int).
- `_TypeId` is negative (-66604 event, -66605 parameter); for tags and properties it is 0.
- The event does not create its own objects. The version has 91 objects, 2 more than 0.0.3: Button_1 and its script OnTapped (scope Faceplate.Event).

**Raising in the type** (script OnTapped of Button_1):

- 0.0.4: `let parameters = {Nr:1, Flag:true};` `Faceplate.RaiseEvent("EvTest", parameters);`
- 0.0.5: `Faceplate.RaiseEvent("EvTest", { Nr: 5, Flag: true });`

The event name is in the script text; there is no link from the script to the event.
