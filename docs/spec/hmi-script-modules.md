Code: `IScriptAttributes.Code` is the same token table as for screen scripts (see `Hmi.script`).

- The global area contains the text before the function including TIA's comment `/*<auto-generated> ***End of Global definition area*** … </auto-generated>*/`.
- A function contains only its body between the curly braces.

The signature is in `IScriptSignatureAttributes`:

- `IsExported`, `IsAsync`, `HasReturnValue`;
- `FunctionName`: token with reference ID into `IScriptLinkExpandoAttributes`;
- `ParameterList`: u32 overall size, u32 count, count × u32 offset; per parameter u32 size and three u32 field offsets, the third field is varint(n+1) name.

The module text is built as in the export: global area, `\r\n`, then per function `[export ][async ]function Name(p1, p2) {` + body + `\r\n}\r\n`.
