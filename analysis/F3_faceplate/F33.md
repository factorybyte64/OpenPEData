## Finding

- **Alarm control, column list 0x3815** (`{_TypeId 4007, 0x0011 columns, 0x0951 header, 0x021c Font}`, 49 columns `{0x03 name, 0x07 visible, 0x05 width, 0x0523 column ID, 0x3811 header text}`, _TypeId 40016): exactly two values changed: **Name width 100 → 123**, **Alarm class visible True → False**. This is the column list of the alarm view.
- **Second column list 0x3832** (56 columns with column ID 0x3833, _TypeId 40017, including Average/Frequency/Sum… 4097–4104): unchanged; this is the column list of the alarm statistics. (CONTROLS.md called 0x3832 "alarm control"; the view is 0x3815.)
- **Trend control, trend areas 0x3839:** CoreMapArray whose elements are **pe blobs** with a MapT (u32 length, u32 count, u32 offset, element = blob kind 0 with u64 length). Read as a simple map, the blob header `00 1d 03 00` appeared as type code "0x31d00". Content per area (_TypeId 990002): 0x03 name "TrendArea_1", 0x3855 left value axes (990005, "Left value axis_1", Font), 0x3858 bottom time axes (990003, "Time axis - bottom_1"), **0x2150 trends** (990011: 0x385a → GUID of the value axis, 0x382b → GUID of the time axis, **0x0440 data source** `{_TypeId 33307, 0x0b1f → tag}`), 0x386f → GUID of the first trend.
  - 0.0.1: one trend without data source; 0.0.2: **second trend with data source HmiTag_Ext1**.
  - The tag reference 0x0b1f goes via IReferenceExpandoAttributes/ExpandoReferences to an HmiTagData of the hidden device: for it, TIA created a **local tag HmiTag_Ext1 (Int, Default tag table)**. The HMI tag of the same name of HMI_1 is Bool (Openness `get tag`); so the type has its own tag of the same name, with no connection to HMI_1 (as F15).
- **Same format, previously open codes 0x72/0x76:** 0x0934 SelectionItems on ListBox/Radio/CheckBox (FP_Elements) are likewise CoreMapArrays of pe blobs (40010 per entry, 0x024f text); count 3/3/4 = F01 truth. With this, no MapT value remains undecoded in any faceplate sample.
- Toolbars (0x214b/0x214c) and header unchanged.

Openness does not expose columns and trends of the type content (only screens and instances); the column and trend values are fixed expectations from the user's assignment, versions against typesList.
