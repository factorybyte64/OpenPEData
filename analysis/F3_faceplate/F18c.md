# F18c: event handler on the instance via function list

As of 2026-10-31. In the working copy (state F33), on Main, on the container "Faceplate container_2" (FP_Interface 0.0.7), the user switched the handler for the interface event EvTest from script to **function list** (SetTagValue HmiTag_Ext1 = 1, ChangeScreen FP_Basic) and created a second instance "Faceplate container_3" with a script handler. Truth: `samples\F18c_event_funclist_truth\instance_Main_Faceplate_container_{2,3}.json` (Openness itemGet, separate TIA instance, temporary copy, closed afterwards). Background: Siemens 109812366 p. 31 (SIEMENS-109812366.md).

## Finding

- **Function list = `HmiFunctionListEmbeddedData`** (0x00e61003, package Hmi.DL.SystemFunctions) instead of `HmiScriptEmbeddedData` (0x00e31002). Same AttributeSets as a script: `IScriptAttributes` (Language JavaScript, scope Screen.Event, Code), `IScriptDataExpandoAttributes`, `IScriptLinkExpandoAttributes`, `IScriptSignatureAttributes` (FunctionName, ParameterList, **IsAsync True**; the script of container_3 has IsAsync False).
- **Code = JavaScript generated by TIA**, one line per function: `HMIRuntime.Tags.SysFct.SetTagValue("HmiTag_Ext1", 1);` and `HMIRuntime.UI.SysFct.ChangeScreen("FP_Basic", ".");`. Openness shows the same ScriptCode and `// [FunctionListModule]` as the global area (for the script, the default text).
- **References:** ExpandoReferences of the function list to the container, the HMI tag HmiTag_Ext1 and the screen FP_Basic (resolved via IScriptLinkExpandoAttributes as for scripts, H-031). The value 1 is a constant; TIA did not use the event parameter Nr as the value here.
- **Linkage:** container `-EmbeddedScriptChildren->` function list (as for the script); on the script module container of the screen it hangs via **`FunctionListElements` / `FunctionListModule`** instead of `EventElements` / `EventModule`. The old script object of container_2 is deleted.
- `IEventExpandoAttributes.EvTest` on the container changes from `06 00 00 00 00 00` to `06 00 00 00 04 00`; the byte is **not** an identifier of the handler kind (F40: values 0–4 for scripts and function lists).
- Openness: `EventHandlers/#0` with EventType "None" (interface event), Async True/False, ScriptCode as in the file.

## Parser and test

- `faceplates.py`: instance events with `handler` ("functionList" / "script"), `async` and for function lists `functions` = [{function, area, arguments}] from the SysFct lines; text `event OnEvTest (Screen.Event, function list)`.
- `test_faceplates.py`, `check_f18c`: both containers against Openness (ContainedType, position, size, code, async, kind via `[FunctionListModule]`), functions of the list (18 values).
- hmi.py already reads function lists on screen items as events (same relation), without naming the kind; for screens this remains up to the HMI thread.
