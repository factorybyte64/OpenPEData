## Interface tag

**Storage location.** `ILFaceplateTypeData.IFaceplateInterface.TagInterfaceProperties` (CoreMapArray = array of pe:MapT, `COREMAPARRAY.md`), 174 bytes:

```
ae 00 00 00  01 00 00 00  0c 00 00 00          array: length 174, 1 element, element from 12
00 8a 00 00 00 00 00 00 00 00 00 00 00 00 10 01 00 00 00 01 01 00 00 00   blob header (kind 0, 138 bytes)
8a 00 00 00  06 00 00 00  50 00 00 00          map: length 138, 6 entries, values from 0x50
0c 00 00 80  0b 00 00 80  0b 00 00 80  05 00 00 80  05 00 00 80  0b 00 00 80   GUID, Str, Str, i32, i32, Str
06 _Guid  04 Tag  0c _BlDataType  08 _TypeId  09 DataType  05 Name
09 44 a7 e9 3b 88 f2 4d 9a c0 5b 62 e5 09 d1 c1   _Guid e9a74409-883b-4df2-9ac0-5b62e509d1c1
24 00 00 00   Tag          → offset 0x24 in the value area → "C\x0b0)"
29 00 00 00   _BlDataType  → offset 0x29 → "(!({"
00 00 00 00   _TypeId      0
01 00 00 00   DataType     1
2e 00 00 00   Name         → offset 0x2e → "HmiTag_Ext1"
05 43 0b 30 29   05 28 21 28 7b   0c 48 6d 69 54 61 67 5f 45 78 74 31        strings varint(n+1) + UTF-8
```

**New about the MapT format:** type code **0x0b** is a u32 offset (relative to the value area) to a string varint(n+1) + UTF-8, not an inline string. With this, all 55 `IFilter.TypeFilter` of all samples now also decode cleanly (previously 17 of 53). Still open: 0x0e (`NormalizedUmacMeta`, 105) and one `DependencyIdentifiers`.

**References.** `Tag` and `_BlDataType` are names of entries in `IReferenceExpandoAttributes` of the same object. Their value (u32 big endian + 1 byte, as H-031 for scripts) is an index into the `ExpandoReferences` links in stored order, **empty entries `0000:0000:0` counted**:

| Expando | Value | ExpandoReferences[index] |
| --- | --- | --- |
| `C\x0b0)` (Tag) | `00 00 00 00 00` → 0 | HmiTagData HmiTag_Ext1 (`1008:00e5:284c`) |
| – | – | [1] empty |
| `(!({` (_BlDataType) | `00 00 00 02 00` → 2 | DataTypeItemData Bool (`1002:0002:1075`) |

`DataType` = 1 is likely the type code for Bool (can only be checked with F12, several data types); `_TypeId` = 0.

**Tag table of the interface.** The interface tags are not in the "Default tag table" of the hidden device but in a separate HmiTagTableData whose name is a GUID (`703f8240-…`):
`ILFaceplateTypeData -ILFaceplateToTagTable-> table`, `table -TagTableToILFaceplate-> ILFaceplateTypeData`, `-AggregatingFolder-> HmiTagFolder`, `-Content-> HmiTag_Ext1`, `Environment -> version`. The tag itself is a complete HMI tag: `TagTable`, `DataTypeRef` and `IHmiTagStructureAttributes_HmiDataType` → Bool, `IHmiTagAttributes_AcquisitionCycle` → T1s, `ITagAddress.Scope` HMI_ILRT, `IStructureItem.DisplayTypeName` Bool, `VendorData` = empty MapT.

**Hidden device.** FP_Interface now has 89 objects (88 − shell + table + tag); without the table and its tags, the fixed core stays at 79.

**Openness.** The type itself does not expose its interface (typeExport = metadata). Via an instance in the working copy (`itemCreate containedType="V0.0.1\FP_Interface"`), `partGet Interface` returns: 1 element `HmiFaceplateInterface` with `PropertyName` = "HmiTag_Ext1"; Openness does not show a data type there.

## Instance

`ILFaceplateContainerData` "Faceplate container_1", subtype HmiFaceplateContainer:

- Links: `ILScreenItemParent` → Main, `Environment` → project, `Target` → HMI_1, **`IsInstanceOf` → FaceplateLibraryVersionData FP_Basic 0.0.1**; counterpart on the version `IsTypeOf` → container.
- Expandos: Left 130, Top 73, Width 750, Height 300 (= size of the type), Layer (reference to the layer GUID).
- There is no attribute `ContainedType` in storage. Openness shows **`ContainedType` = `V0.0.1\FP_Basic`** (`itemGet`), derived from version and type name. `itemCreate` accepts exactly this notation as well (MCP-060 clarified, feedback in the backlog).

## Parser

`openpedata\faceplates.py`:

- `decode_map` / `decode_map_array`: MapT and CoreMapArray (0x05/0x13 i32, 0x0c GUID, 0x0b string via offset).
- `interface.tags`: name, data type (via `_BlDataType`), tag and acquisition cycle (via `Tag`), GUID, `_TypeId`, data type code; `interface.tagTable`; `properties` and `events` are decoded the same way, but without a sample yet.
- Instances carry `containedType` (`V<version>\<type>`).
- The fixed core does not count the interface tag table and its tags.

`tests\test_faceplates.py`: F05 against `typesList.json` (40 values), `itemGet` (screen, ContainedType) and `partGet Interface` (name), plus interface tag (name, Bool, tag), instance, object counts.
