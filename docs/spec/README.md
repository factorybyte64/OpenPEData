# Format documentation TIA Portal V21

Single directory for all documents on the TIA V21 file format (user, 2026-10-23). Entry point: `00-overview.md`, then `hypotheses.md`.

- `<structure>.md`: established format description with evidence.
- `<structure>.parser.md`: parser version of the same structure (formerly here under the name without `.parser`), closer to the code; merging is pending.
- `hypotheses.md`: hypotheses H-NNN. `LOG.md`: lab notebook, append only.
- `unified-*.md`: formerly `samples\UNIFIED-*.md` or `samples\F01_hmi_allobjects_objects.md`.
- `prior-art.md`, `faceplate-doc-features.md`: research.

References to `../PLAN*.md` point to the plans in the project folder of the knowledge base (not in the repo).
