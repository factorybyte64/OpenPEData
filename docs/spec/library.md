## Master copies in detail (L2, established)
Evidence: samples 021, L10–L15 (MANIFEST "Step L2"), truth masterCopiesList; report `analysis\L2_mastercopy\REPORT.md`. library.py over 134 sources without errors, L10–L15 equal to ground truth.
- **Skeleton:** always the same structure of live objects, each with Environment → LibraryMasterCopyData: Subtype IECPL (FB, FC, DB); Devices → shell DeviceData (IsShell, 584 B) → DeviceItems → copy of the S7ControllerTargetData (generic CPU CPU_15XX_Unspecific, H-L2-4); VisibleParts → full copy of the block; Categories only for blocks with comments; RelatedPackage S7PSW plus culture links. Subtree closed (no links to the outside, only null entries in UsedParts as in the original).
- **Copy versus original:** identical are domain attributes, names, interface names/GUIDs, TrackingGuid, SourceObjectID; new are object GUID, OID, timestamps, fingerprint (ValidState 1 → 0), IsShell False → True. OIDs assigned consecutively. Changed shared objects: MC system folder (+AggregatedElements), S7PSW (+RelatedObject), CoreCulture (back links), ProjectData, CorePersistenceInfo.
- **Dependencies (H-L2-3):** called blocks and UDTs as name stubs (UserTypeData UDT_Motor 368 B instead of 1252 B; CodeBlockData FB_Iface 369 B instead of 3213 B), link TRefParent → copied folder (inverse TextualReferences); for the UDT additionally the interface root `_BIVE:UDT_Motor/<guid>` copied fully and identically.
- **CoreObjectData:** header u32 length 34, count 1, offset 12; element length 22: ObjectRole i16 = 1 (SelectedObject), Option null, ParentObjectId −1, SourceObjectId 0, VisualPartIndex 0. NonCoreObjectData empty array (8 B), BinaryData empty blob header (20 B).
- **Scope IDs:** {type ID decimal-OID decimal} of the source objects (H-L2-5); Persistence contains the absolute source path with machine name (personal data); projectId = session GUID.
- **Order:** AggregatedElements of the MC folder = creation order (like masterCopiesList). Each master copy has its own set of shell device, target, folders and stubs.
- **Instantiating (L13):** no trace of origin (no link/attribute to the master copy), new GUIDs, SourceObjectID = the new block itself; in a device without the UDT a UDT stub with interface root is created again (Openness does not show it); an existing UDT gets a second interface root with the same name.
- **Deleting (L14):** 26 tombstones (49 B) for the master copy and 25 copies, first shared objects, then copies in OID order; back links at folder, package, culture removed. The .zap21 contains no tombstones (compacted).
- **Writing a master copy from a block:** copy the subtree with new OIDs/GUIDs, shell device + generic target, folders, name stubs (UDT with interface root), LibraryMasterCopyData with CoreObjectData and SharedRawData, links in folder/package/culture. Open: icon (PNG per block kind).
- **Not creatable via MCP (open):** master copies in subfolders, multiple selection, master copies from UDT/tag table/device (project library), global library (L6).
- **Parser proposals:** sort attribute_sets (H-020), decode structure/array values with u32 length generically (fixes values ≥ 128 B), move library.py to parser\openpedata (L5).

## Usages and version status (L4, established)
Evidence: samples L16–L21, report `analysis\L4_instances\REPORT.md`; library.py (now `parser\openpedata\library.py`, commit bcf43ee) green against instancesList/typesList.
- **The version status of an instance** is stored three times: link IsInstanceOf → version object (inverse IsTypeOf, authoritative); CurrentLibraryInterface → interface root `_BIVE:<Name>/<VersionGuid>` in the `<UDT|FB|FC>_TypeLibraryPartContainer` (shared by all instances of the version and the content copy); expando UserTypeVersionGUID on its own interface root. Version number only on the version object. No instance list on the type; instancesList = IsTypeOf links, filtered by target. InWork: only IsInstanceOf.
- **"Outdated" is not stored** (H-L4-1): release via device A does not change a single byte on the object in device B; Openness LibraryConformanceStatus stays "library-conformant". Outdated = derived (a higher Committed version exists), separate from "on default version?" (an instance can hang on the default version and still be outdated).
- **Release with several devices** links only the edit instance; context device of the content copy = device of the edit instance. InWork number = highest existing + 0.0.1. BlockToVersionElements only for instances released in place. `_` prefix of the interface root ⇔ IsConstant (1591/1591).
- **Discard** deletes the InWork version AND the instance with its parts (tombstones, also for objects never persisted) and recreates the instance on the previous version (new OIDs, CreationTime = discard time). UpdateProject presumably works the same (to be checked, MCP can do it now).
- **Default version with 2 devices:** only TypeToDefaultVersion/DefaultVersionToType + ModifiedTime change, instances unchanged.
- **Open:** real update, deleting version/type, type obsolete (IsObsolete/IsSetAsNonUpdateable) and folders, now catchable up with the updated MCP server (L22–L26); InWork content still not changeable.
